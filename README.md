# Proyecto de Métodos Numéricos

Aplicación para resolver sistemas de ecuaciones lineales mediante Gauss-Jacobi y Gauss-Seidel.

## Requisitos

- Python 3.10 o posterior
- Tkinter, incluido normalmente con Python en Windows
- Dependencias de `requirements.txt`

Instala las dependencias con:

```powershell
python -m pip install -r requirements.txt
```

## Ejecución

Interfaz gráfica:

```powershell
python interfaz_grafica.py
```

Versión de consola:

```powershell
python demo.py
```

La aplicación ofrece ejercicios precargados, ingreso de sistemas personalizados, gráficas de convergencia y exportación de resultados.
